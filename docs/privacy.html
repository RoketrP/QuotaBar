隐私政策

QuotaBar 以本地处理为原则，不运营开发者后端，也不收集账户或用量数据。

开发者不收集的数据

  • ChatGPT 登录凭证、Cookie 和用户邮箱；
  • Codex 用量、额度信息和设备标识符；
  • 分析数据、广告标识符或崩溃遥测；
  • 通过爱发电、微信或支付宝赞助产生的付款信息。

本地处理

QuotaBar 通过内嵌的 Codex 官方组件读取用户主动授权账户的额度。登录凭证由该组件保存在 macOS App Sandbox 管理的本地容器中，不发送给 QuotaBar 开发者。

默认仅在运行内存中保存额度快照。自 1.3.0 起（开发中），用户可主动启用本地历史，保存最近 30 天的采样时间、额度窗口标识、窗口长度、剩余比例与重置时间；不保存邮箱、令牌、聊天内容或 token/费用统计。关闭记录会保留已有采样，可在“历史”窗口导出 CSV 或清空。

为防止不同账户的历史混合，本机偏好中保存邮箱的 SHA-256 指纹，仅用于账户变化检测，不写入历史或导出文件，不上传。退出账户或检测到账户变化时清空历史；演示数据不记录。开机启动设置由 macOS 系统服务管理。

第三方服务

用户选择登录或读取真实额度时，App 会与 OpenAI、ChatGPT 或 Codex 服务通信，其处理受对应服务条款和隐私政策约束。

“AI / Codex 官方动态”默认关闭。用户主动启用后，App 每天最多自动访问一次 OpenAI News 与 GitHub Changelog 的官方 RSS；用户点击手动刷新时会立即访问。App 仅在本机缓存公开标题、摘要、发布日期和链接，请求不会附带 ChatGPT 登录信息或 Codex 用量数据。

爱发电赞助入口只会在用户点击后通过默认浏览器打开第三方页面，其访问和付款受爱发电的条款与隐私政策约束。微信和支付宝入口是静态二维码。QuotaBar 不会自动发起付款，也不会接收支付结果。

删除与联系

QuotaBar 没有开发者服务器或用户数据库。用户可在 App 内退出账户，并通过删除 App 与本地容器清除本地数据。

隐私问题和普通反馈请通过 GitHub Issues 提交，敏感安全问题请遵循仓库的 Security Policy。

QuotaBar 是独立第三方开源项目，不是 OpenAI 官方产品。
